# ARMAAN Residences

# Build the Official Launch Website for ARMAAN – Santacruz West by Poonam Group



Create a stunning, ultra-premium luxury real estate landing page for **ARMAAN**, a boutique residential project in **Santacruz West, Mumbai** by **Poonam Group**.



This is the official launch website. The design must feel luxurious, minimal, emotional, and editorial — inspired by Apple, Lodha, Aman Resorts, and high-end architecture magazines.



## Tech Stack



* React + Next.js

* Tailwind CSS

* Framer Motion

* Lenis Smooth Scroll

* Fully Responsive

* SEO Optimized
